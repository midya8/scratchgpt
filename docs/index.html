02 / STATE, NOT A SLOGAN

Thirteen places to stop. One destination.

Each run ends at update 12. The exact-resume arm saves and restores every parameter, both Adam buffers, the update clock, train/evaluation PCG64 states, data identity, options and runtime fingerprint. The same-environment Python audit compares the complete final state bit for bit.

Stops at 0 and 12 are controls: no prior random stream is lost at 0; no future update remains at 12. Resetting evaluation RNG alone changes future scheduled validation samples, not training weights. These are small-run counterexamples, not a performance benchmark.

What is actually checked?

JSON canonical metadata plus raw float32 parameter/moment bytes form the full-state digest. Cross-version regeneration uses numerical tolerances and ignores runtime-specific digests. Atomic replacement prevents a failed save from truncating the previous checkpoint, but is not a promise against every filesystem or power-loss failure.

05 / WHAT THIS DOES NOT ESTABLISH

Exact continuation has a boundary.

Same environment means the same NumPy build, Python version, machine/platform and recorded thread settings. Floating-point execution and random streams are not promised identical across machines, BLAS builds or versions. The loader refuses a mismatched fingerprint rather than silently calling it exact. A matching fingerprint is necessary, not proof that every runtime detail is identical.

A file's hash binds data identity; it does not make the text trustworthy or licensed. The checkpoint loader disables pickle, bounds archive size, validates all fields and shapes, and refuses legacy weight-only files for continuation. It does not authenticate an arbitrary checkpoint. The original committed Shakespeare inference checkpoint remains sampleable.

Training and gradient code are Python/NumPy. The browser only replays the Adam equation from recorded actual gradients and runs scalar forward inference. Edited scalar settings are local counterfactual arithmetic, not a newly trained trajectory. No GPU, training-speed, generalization or new-algorithm claim is made.

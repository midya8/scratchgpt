Native Tensor graph

Graph-reachable Tensor.data logical elements after the loss forward. Parameters and mask excluded. Views count per Tensor, even when storage aliases. Closure arrays, gradients, audit copies, Python objects and BLAS buffers are not counted.

Independent browser scalar graph

Actual reachable scalar nodes after the loss forward, parameters excluded. This has a different granularity and arithmetic from the native Tensor graph. Do not compare these two counts as identical memory measurements.

Neither count is allocator memory, process RSS, a peak-memory measurement or a speed benchmark. The audit itself holds full reference reports, weights, gradients and both result arms.

05 / PRECISE BOUNDARIES

More compute, less retained graph.
No free lunch claimed.

The Python path recomputes the original NumPy Block modules, uses their existing backward rules, and leaves the original Tensor.backward, GPT forward, training defaults and continuation format untouched. A separate scalar JavaScript engine implements the full small GPT and its backward rules here. Native float32 and browser float64 are checked within tolerance, not called bitwise identical.

Only deterministic dropout=0, first-order gradients and unchanged parameters/inputs between forward and backward are supported. Native region guards reject changed inputs, weights, mask or block settings. Discard gradients after any failed backward pass. Tied parameters within a native region are rejected. Arbitrary stochastic or stateful callables, higher-order gradients, optimal checkpoint scheduling and GPU kernels are outside this implementation.

The original 419,328-parameter Shakespeare checkpoint is tested on every parameter gradient for both block grouping choices, but it is not retrained or rebenchmarked. The browser fixtures are separate tiny synthetic models, some after three original eager Adam steps. Changing a control gives one new derivative and SGD arithmetic comparison, not a new training trajectory or generalization result.

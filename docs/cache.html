KV bytes mean native ndarray payload only. They exclude the copied weights, token history, temporaries, Python/BLAS storage, allocator overhead and peak memory. Browser arrays have different storage. Matrix counts are not a hardware cost model.

What stays outside this experiment

The native cache is an inference-only snapshot. Later training does not update its copied weights. Low-level append refuses overflow; rolling advance rebuilds all layers at every context crop. It does not discard extra context to manufacture a speed win.

Native float32 and browser float64 arithmetic are compared numerically, not called bitwise identical. Close logits can still change a sampled token near an RNG threshold. The original sampler is unchanged. This is not a new attention algorithm, GPU kernel, inference server or general speed guarantee.

The browser controls are tiny synthetic models, some after three original Adam updates. They are not the Shakespeare model. The archived native benchmark does use that checkpoint without retraining it. Its CPU model was not recorded, so these timings should not be used for hardware comparisons.
